# 训练算法与评分规则

本项目的分数是可复现的软件工程指标，仅用于本次任务表现的反馈，不是医学量表、诊断或疗效结论。算法均为无 Android 依赖的 Java 类，可独立单元测试。相同输入、配置和完成状态得到相同输出。

## 1. API、坐标与时间

- `TrainingAlgorithms.Point(x, y, timeMs, breakBefore)`：坐标、相对单调毫秒、是否新笔画。`breakBefore=true` 不与上一点连线。
- `TrainingAlgorithms.tracePath(subtype, difficulty)`：生成直线、顺时针圆或由内向外的顺时针螺旋，返回不可变目标点集合。
- `TrainingAlgorithms.analyzeTrace(samples, guide, difficulty, completed)`：轨迹结果。
- `TrainingAlgorithms.Trial(stimulusNs, responseNs, correct, timeout)`：每次错误点击、成功点击或一次目标超时一条记录。
- `TrainingAlgorithms.analyzeReaction(trials, expectedRounds, difficulty, completed)`：反应统计。
- `TrainingAlgorithms.analyzeCoordination(successfulTapTimesNs, errors, expectedTargets, difficulty, subtype, startedNs, endedNs, completed)`：协调统计。
- `DifficultyRecommender.recommend(sessions, type, currentDifficulty)`：最近五次有效完成记录的难度建议。

绘图区使用居中正方形。边长为 `S=min(width,height)`，左上角为 `(left,top)`，输入坐标为 `((x-left)/S, (y-top)/S)`；目标和用户路径共用该坐标系。`Geometry.normalize` 可将原点已移至绘图区左上的像素坐标按 S 缩放。不能用实际路径包围盒归一化，否则短路径会被放大成完整轨迹。纯算法支持暂时超出 [0,1] 的有限坐标，并将其计入偏差与长度；超过绝对值 1,000,000 的归一化坐标视为异常以避免溢出。当前 UI 采样策略是丢弃绘图区外触点，并把重新入区的点标为新笔画；跨区缺口不补画、不增加覆盖。

日期采用系统日期时间；算法时长采用单调时钟，与系统日期修改无关。训练 View 使用 `SystemClock.uptimeMillis()` 计算前台活动时长，扣除明确暂停的时段；传入反应和协调算法时乘以 1,000,000 转为纳秒。纯算法也兼容 `elapsedRealtimeNanos()`。相对单调时间从 0 开始合法。结束与开始之间无量测值的指标保持 `null`，例如没有成功点击时，平均及最快反应时间为空。

## 2. 集中配置

唯一配置入口为 `TrainingAlgorithms.config(difficulty)`，难度 0/1/2 分别为简单/普通/困难。传入越界难度时截取到 0～2。

| 配置 | 简单 | 普通 | 困难 |
| --- | ---: | ---: | ---: |
| 轨迹允许偏差 τ（绘图区边长比例） | 0.045 | 0.032 | 0.023 |
| 点击目标半径（边长比例） | 0.090 | 0.072 | 0.055 |
| 单目标反应时限/ms | 2500 | 1800 | 1200 |
| 反应训练轮数 | 8 | 10 | 12 |
| 顺序点击目标数 | 6 | 8 | 10 |
| 连续点击目标数 | 12 | 18 | 24 |
| 轨迹任务时限/ms | 60000 | 50000 | 40000 |
| 协调任务时限/ms | 60000 | 50000 | 40000 |
| 圆半径 | 0.310 | 0.335 | 0.360 |
| 螺旋圈数 | 1.25 | 1.75 | 2.25 |

所有难度共用：最短有效反应 80ms、最小有效点击间隔 50ms、轨迹最短时间 500ms、最少 8 个原始采样点、覆盖率下限 70%、实际/目标路径长度比 0.65～2.2。80ms 与 50ms 是识别预按、重复触摸等异常输入的工程阈值，不代表人的健康标准。

## 3. 轨迹几何与评价

### 3.1 均匀弧长采样

目标轨迹先生成 257 个点，再统一按弧长重采样为 N=128 个点。对每个连续笔画，线段长度为 `l_i=√((x_i-x_(i-1))²+(y_i-y_(i-1))²)`；累计长度 `s_i=Σ l_i`。多笔画的跳跃不计入长度。第 k 个采样点的累计位置为 `u_k=kL/(N-1)`，找到所属真实线段，按 `(u_k-s_(i-1))/l_i` 线性插值坐标及单调时间。保留首尾，静止重复点不增加弧长；零长度路径返回单点。

实际轨迹也以相同 N 重采样，使触摸事件密度和手机采样频率不会直接改变空间权重。距离计算采用点到真实线段的投影距离，投影参数限定在 [0,1]；零长度线段退化为点距离。不跨抬手后的笔画连接。

### 3.2 偏差、覆盖与准确度

令实际均匀采样点为 A_k，目标均匀采样点为 T_k，目标原始折线为 G，实际原始折线为 P。

- 平均偏差 `D=Σ distance(A_k,G)/N`，输出单位为绘图区边长比例。
- 顺序偏差 `D_order=Σ ||A_k-T_k||/N`，用于区分反方向、折返及乱序描绘。
- 覆盖率 `C=#{k:distance(T_k,P)≤τ}/N`，范围 [0,1]。
- 最近路径准确度 `A_near=clip(1-D/(2τ),0,1)`。
- 顺序准确度 `A_order=clip(1-D_order/(4τ),0,1)`。
- 轨迹准确度 `A=0.75 A_near+0.25 A_order`，范围 [0,1]。

覆盖是目标到实际的距离，偏差是实际到目标的距离；两者配合，既惩罚漏画，也惩罚大量额外乱画。顺序误差使逆向画圆即使覆盖完整，也不能当作按要求完成。

### 3.3 操作稳定性

先比较实际与目标的相邻二阶差分，扣除目标本身的曲率：

`J=mean(|| (A_(k-1)-2A_k+A_(k+1))-(T_(k-1)-2T_k+T_(k+1)) ||)`。

空间稳定性 `S_space=1/(1+J/(0.5τ))`。它度量额外抖动，平滑圆和螺旋不会因自身曲率被直接判为抖动。

对重采样实际点，取正时间间隔形成速度 `v_k=||A_k-A_(k-1)||/Δt_k`。速度均值 μ、总体标准差 σ，变异系数 `CV=σ/μ`。时间稳定性 `S_time=1/(1+CV)`；缺少两个可用速度时取 0。最终稳定性 `S=0.65 S_space+0.35 S_time`。

### 3.4 有效性与综合分

同时满足以下条件才设置 `valid=true`：

1. 用户完成任务，原始坐标有限、时间不逆序，至少 8 个有效采样点。
2. 轨迹时长在 [500ms, 当前难度时限]。
3. 实际起终点分别距目标起终点不超过 2τ。
4. 每次抬手后的新笔画与前一笔尾端的间隔不超过 2τ；不自动连接笔画。
5. 实际/目标路径长度比在 [0.65,2.2]。
6. 覆盖率 C≥0.70、平均偏差 D≤2.5τ、顺序偏差 D_order≤4τ。

理想时间 `t_ideal=max(1800, L_target×(4200-500×difficulty)) ms`；时间得分 `T=min(1,t_ideal/durationMs)`。

综合分 `Score=100×(0.40A+0.30C+0.20S+0.10T)`。输出限定 [0,100] 并四舍五入到一位小数。

任何有效性检查失败，综合分为 0、`valid=false`，同时返回明确原因。可计算的真实偏差、覆盖等仍保留用于反馈；未完成/中断也不能获得有效训练成绩。`TraceResult` 的 `accuracyAvailable/deviationAvailable/coverageAvailable/stabilityAvailable` 决定每个指标是否可用；存储时不可用项必须写为 `null`。静止点可计算实际位置偏差和有限覆盖，但稳定性不可用。空路径的默认零值不表示已量测或优秀。

## 4. 反应时间与评分

目标出现时记录单调纳秒 `stimulusNs`，点击时记录 `responseNs`，`RT=(responseNs-stimulusNs)/1,000,000` ms。仅成功点击的 RT 进入平均值及最小值。错误点击计入错误次数，不自动结束本轮；超时单独计数。

成功数 H、错误点击数 E、目标超时数 U、计划轮数 R：

- 点击准确率 `A=H/(H+E)`；没有点击时 A=0，持久化时可置为空以表示没有测量。
- 平均反应 `meanRT=Σ RT_success/H`，最快反应 `min(RT_success)`；H=0 时两者为空。
- 完成比例 `C=H/R`，因此超时降低此项。
- 速度得分 `V=clip(1-(meanRT-80)/(timeoutMs-80),0,1)`。
- 综合分 `Score=100×(0.45A+0.35V+0.20C)`。

必须完成全部 R 轮且至少成功一次才有效。成功反应需在 [80ms, 单轮时限]，点击响应不能早于刺激、点击时间必须严格递增、同一刺激只允许结束一次；重复成功/重复超时或在已结束目标上点击都视为异常。未完成、零成功或异常数据综合分为 0。超时不加入准确率分母，平均反应不混入错误点击与超时。

## 5. 协调性训练

训练层只在一个 `ACTION_DOWN` 中计一次点击，数字模式必须点当前正确目标；错误不前进。小于 50ms 的重复触摸不计成功，按错误记录。

输入成功点击单调时间数组 `t_1…t_H`、错误数 E、目标数 R。准确率 `A=H/(H+E)`。相邻间隔 `I_i=(t_i-t_(i-1))/1,000,000` ms；平均间隔为 `mean(I)`，节奏稳定性 `S=1/(1+CV(I))`。少于两个点击时平均间隔与稳定性为空，不能以 0 冒充已测量结果。两个点击只有一个间隔，其 CV=0，但正式配置目标数均≥6。

总时间 `durationMs=(endedNs-startedNs)/1,000,000`，含首个目标出现至首次成功的等待。理想单目标时间：顺序模式 `1600-250×difficulty` ms；连续点击模式 `750-150×difficulty` ms。时间得分 `T=min(1,R×idealPerTap/durationMs)`。

综合分 `Score=100×(0.45A+0.30T+0.25S)`。

完成全部且仅 R 个成功点击、总时间正数且不超过任务时限、所有点击位于任务时间内、相邻成功间隔≥50ms、错误数非负，才能有效。逆序、零间隔、极端高频、数量不符及中断均无有效分。

## 6. 难度推荐

`Session(type,difficulty,score,valid,completed,endedAt)` 是纯 Java 推荐输入。先限定同用户仓储提供的记录，再由算法筛选同类型、同难度、有效且完成、成绩有限且在 [0,100] 的会话，按结束时间倒序选最近 5 次。不同训练类型与难度的数据不混算。

- 少于 5 次：`sufficientData=false`，均值为空，不给升降结论。
- 5 次平均≥85：建议提高一级，最高为困难。
- 5 次平均<60：建议降低一级，最低为简单。
- 其他情况或达到边界：建议保持当前难度。

返回样本数、平均分、推荐难度与原因。推荐只显示给用户，由用户选择，算法不自动修改训练设置。

## 7. 边界处理与验证范围

空集合、空元素、非有限坐标、静止点、零间隔、逆序时间、未触摸、中断、极短路径、直线抄近路、重复绕圈、跨笔画跳跃、错误方向、随机乱画、超时、零成功和高频触摸均有明确无效或空指标行为。

对应测试为 `TrainingAlgorithmsTest` 与 `DifficultyRecommenderTest`：包含弧长均匀性、分辨率一致性、三种轨迹三种难度的理想路径、反作弊与错误时间边界、反应准确率分母、节奏统计、推荐阈值与最近五次筛选。运行：`./gradlew testDebugUnitTest --tests 'com.fingerrehab.algorithm.*'`。这些是软件规则和计算验证，真实触屏手感、机型采样差异仍需真机验证。
