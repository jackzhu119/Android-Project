# 版本变更

## 1.0.2（versionCode 3）

本轮改善草稿、导航和异常历史兼容；数据库仍为版本 3，评分权重与权限范围不变。最终构建成功，16 类共 166 项测试通过（0 失败/错误/跳过），Lint 为 0 errors/25 warnings，APK 清单与签名复核通过；API 26 软件模拟器已验证升级保留、未开始返回、草稿选择/计划保存与简单连续点击；强停重开后两条有效记录与每日计划保留，首页 2/5、40%。

- 档案与计划有未保存修改时，返回可选择保存、放弃或继续编辑；草稿和原始基线跨旋转保留。
- 导航按页保留滚动，训练难度/统计筛选持久化；历史返回与旋转保留位置，删除避免重复弹框；图表补齐无障碍读值和前后项动作，设置版本从 PackageManager 获取。
- 未开始浏览训练不产生记录或快照；双击、旧弹框回调与 API 26 恢复提示处理收紧；已完成待保存的恢复保留原状态和成绩。
- 统一有效完成条件为有效标记、completed、有限 0～100 分。旧坏分排除有效成绩/每日目标，保留历史、次数、时长和原数据库内容；新写入校验不变。
- 单条报告摘要先读，明细按 64Ki Unicode 字符分块，超 4Mi 字符仅提示明细不可用；坏轨迹点断笔，异常分显示“—”。
- 可读明细的全部事件按每组 30 条分页，单条坏事件独立提示，未知时间不显示为 0；结果页保留事件页码和滚动。

## 1.0.1（versionCode 2）

本轮围绕数据可比性、训练边界和提醒可靠性完善现有功能。最终构建成功，117 项测试通过，Lint 为 0 errors/21 warnings（减少 18 个警告），生成 6 张离屏预览；API 26 软件模拟器另完成安装、UI 建档、简单直线 98.9 分及强停重开持久化冒烟，其他任务/通知与真机验收范围见 [TESTING.md](TESTING.md)。

- **统计与推荐：** 增加任务子类型和难度筛选。只有同一任务、同一难度才显示成绩趋势线；混合范围保留真实汇总和次数，并明确类型对比图的汇总口径。难度建议也限定同一任务、同一难度的最近 5 次有效完成。
- **训练状态：** 轨迹按完整前台活动会话检查总时限；恢复后丢弃暂停前的历史触摸，重置旧手势。会话绑定创建时的档案，防止切换档案后保存到其他用户。
- **保存恢复：** 保存失败后保留原状态与待执行动作，重试成功仍执行原来的重开、退出或查看报告。冷启动后进入训练页可按档案找回进度，选择恢复、保存中断并开始本次，或保留数据并返回。
- **触摸性能：** 画布继续接收真实采样，文本指标以 50 ms 节流刷新，缓存参考轨迹和绘图对象，减少高频触摸时的无效布局与分配。
- **提醒与计划：** 同一计划再次打开应用时保留已到时间但等待系统投递的闹钟；重启和时钟/时区广播强制重排。计划写入失败、已保存但调度失败分别提示，补充 Android 13 通知权限路径。
- **数据访问：** 拒绝跨档案写入与 NaN/无穷大等非法测量，提供按任务/难度筛选、摘要和分页查询，历史改为每页 30 条 SQL 分页。数据库升至版本 3，仅新增复合索引并保留原记录。
- **界面与验证：** 按钮加入点击波纹及禁用状态，长指标可换行，图表支持点选读值、方向键与无障碍描述；新增原生 Skia 离屏渲染实际 Android View 的预览测试，包含自动构造 MotionEvent 完成螺旋任务后的正式评分结果。预览属于 Robolectric/JVM 输出，不是模拟器或真机截图。

本轮没有改变评分权重、最低 Android 版本或权限范围。提醒仍为非精确定时，评分仍为工程指标。
